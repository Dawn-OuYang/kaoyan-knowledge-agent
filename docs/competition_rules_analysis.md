# 2026 C4-AI 昇腾赛道规程分析

读取日期：2026-07-21  
依据文件：`2026“中国高校计算机大赛-人工智能创意赛”通知_规程（盖章版）.pdf`

## 和本项目直接相关的要求

本项目参加的是昇腾赛道，不是普通应用创新赛。规程要求作品围绕昇腾 AI 全栈技术、昇腾 NPU 和 Agent Skill 场景展开。对于“千问 3.5 模型优化创新”方向，项目需要基于 Qwen 3.5 创建 Skill，完成模型向昇腾 NPU 的迁移与性能优化，并展示 Skill 的应用价值。

因此本项目不能只交一个网页问答 demo。正式技术定位应为：

```text
考研知识库问答 Agent Skill
  + 研招网/院校官网等官方来源 RAG
  + MindSpeed-MM/Qwen3.5 适配
  + 昇腾 NPU 迁移、微调、推理和性能验证
  + 功能、精度、性能报告
```

| 评分项 | 分值 | 项目响应 |
| --- | --- | --- |
| 创新性 | 30 | 面向考研择校、专业课、真题解析和复习规划的一体化 Agent Skill；强调官方来源溯源和年度风险提示 |

| 性能优化 | 40 | 基于附件 7 MindSpeed-MM/Qwen3.5 样例准备转换、微调、评测、报告脚本；复赛必须在昇腾 NPU 实测回填 |

## 当前边界

本机没有昇腾 NPU、CANN、torch_npu 和 Qwen3.5 权重，所以当前不能声称已完成真实 NPU 性能优化。当前版本完成的是可运行应用层、Skill Runtime、数据样例、评测样例和昇腾适配脚本骨架；复赛阶段必须在昇腾环境跑通并回填真实精度与性能数据。
