# 答辩演示脚本

目标：用 5-7 分钟证明项目不是普通聊天页面，而是“可溯源考研知识库 Agent + 昇腾技术路线”。

## 1. 开场定位

一句话：

> 我们做的是面向考研专业课和院校信息核验的知识库问答智能体，重点解决资料分散、年份易混、回答无来源和普通大模型幻觉的问题。

本项目示例范围：

- 专业方向：计算机408、通信工程、法学。
- 示例学校：沈阳工业大学、北京理工大学、上海交通大学、清华大学。
- 官方来源：研招网、学校官网、研究生院官网、学院官网。

## 2. 演示问题顺序

### 演示 1：专业知识问答

模式：知识问答  
专业：计算机  
问题：

```text
顺序表和链表的区别是什么？
```

讲解点：

- 系统不是直接闲聊，而是先检索知识库。
- 回答会显示引用来源和置信度。
- 适合专业课概念复习。

### 演示 2：真题解析

模式：真题解析  
专业：通信工程  
问题：

```text
真题解析：采样定理为什么要求采样频率至少为最高频率的两倍？
```

讲解点：

- 真题解析 Agent 会补充考点定位、作答结构、易错提醒。
- 对公式类、概念辨析类题目都能按考研答题口径组织。

### 演示 3：院校咨询

模式：院校咨询  
专业：全部  
问题：

```text
清华大学通信工程相关方向应该看哪个学院官网？
```

讲解点：

- 系统命中清华大学电子工程系官网。
- 院校信息不是让模型凭记忆答，而是使用研招网、研究生招生网、学院官网交叉核验。

### 演示 4：时效风险

模式：院校咨询  
专业：全部  
问题：

```text
今年清华大学计算机专业招生人数是多少？
```

讲解点：

- 涉及“今年、招生人数”等时效信息，系统会提示以对应年份官方通知为准。
- 这是教育问答场景里降低误导风险的关键设计。

### 演示 5：复习规划

模式：复习规划  
专业：法学  
问题：

```text
法学专业课冲刺阶段怎么复习主观题？
```

讲解点：

- 复习规划 Agent 会结合阶段、目标和知识库输出计划。
- 后续可加入用户画像：目标院校、剩余天数、基础水平。

## 3. 昇腾技术路线怎么讲

> 当前 Web Demo 是应用层，用于展示考研 Agent 工作流；模型层按昇腾赛道附件 7 对齐 MindSpeed-MM/Qwen3.5。我们已经准备了 Qwen3.5 HF 权重转 DCP 脚本、MindSpeed-MM FSDP 微调配置、训练启动脚本和考研 SFT 数据。上昇腾环境后，会补齐功能验证、精度日志和性能分析报告。

## 4. 评委追问速答

问：你们的数据从哪里来？  
答：三层来源：研招网负责招生单位、招生简章、硕士目录等官方核验；学校研究生院和学院官网负责专业细则；专业课知识库负责概念、真题和复习内容。

问：怎么防止模型胡说？  
答：先检索资料卡，再生成回答；没有来源就降置信度；涉及年份、人数、参考书、分数线时必须提示以官方通知为准。

问：用了昇腾哪里？  
答：应用层与模型层解耦，模型层计划基于 MindSpeed-MM/Qwen3.5 在昇腾 NPU 上运行，按附件要求输出精度日志和性能分析报告。

问：现在有没有真实 NPU 数据？  
答：当前本地环境没有昇腾 NPU，因此不虚报性能数据。项目已经准备好脚本和模板，上昇腾环境后复跑并回填。

问：为什么选这几个专业和学校？  
答：计算机408、通信工程、法学覆盖不同答题形态；四所学校覆盖不同地区和层次，便于展示跨专业、跨院校的信息核验能力。
