# 比赛要求核对记录

## 已确认的公开信息

来源：2026 中国高校计算机大赛-人工智能创意赛官方页面 `https://developer.huaweicloud.com/c4ai.html`，读取日期：2026-07-21。

- 竞赛名称：2026 中国高校计算机大赛-人工智能创意赛（C4-AI）。
- 赛项包含：鸿蒙高校创新赛、昇腾 AI 创新大赛。
- 招募对象：中国内地及港澳台地区高等学校在读学生，含专科、本科、硕博研究生等。
- 参赛队员不限专业。
- 可单人或自由组队，队伍人数最多不超过 3 人。
- 允许跨学校、跨专业组队。
- 同一参赛队员只允许报名参加一个队伍。
- 每个参赛队必须有一名指导老师。
- 指导老师必须是参赛队队长所属高等学校的正式教师。
- 晋级复赛阶段需要提交报名表，并由学校教务部门盖章或指导教师/教务老师/辅导员签名。
- 报名截止后，每队在复赛作品提交截止日期前有且仅有一次队员信息修正或更换机会，并需书面申请。
