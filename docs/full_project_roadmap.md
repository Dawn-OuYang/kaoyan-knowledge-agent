# 完整项目路线图

项目名称：考研各专业知识库问答智能体

## 总目标

做成一个面向考研备考场景的 Agent Skill：用户输入专业课、真题、院校或复习规划问题，系统自动检索可信知识库，调用 Qwen3.5/MindSpeed-MM 推理服务生成回答，并返回引用来源、置信度和风险提示。工程上必须同时支持本地演示、Skill API 调用、昇腾 NPU 迁移、精度测试和性能分析。

## 初赛包，截止 2026-07-26 24:00

目标：保证作品能按规程提交，并能证明不是空想。

已完成或本轮补齐：

- 约 1000 字初赛创意书。
- 本地最小可运行 demo：网页工作台。
- Skill Runtime：`/api/skill/invoke`。
- 命令行 Skill 调用：`scripts/skill_cli.py`。
- 本地规则回归：`scripts/run_eval.py`，只验证固定样例工程行为，不代表模型精度。
- 功能验证日志：`scripts/functional_test.py`。
- MindSpeed-MM/Qwen3.5 昇腾适配目录：`ascend/`。
- 初赛源码压缩包打包脚本。

初赛提交建议：

- 提交创意书。
- 同时提交源码/demo 压缩包，虽然 demo 是可选项，但这会增强可信度。
- 在创意书中明确说明：当前初赛版本为可运行 Skill 原型，复赛将在昇腾 NPU 上完成 Qwen3.5 迁移、微调和性能报告。

## 复赛包，截止 2026-09-30 24:00

目标：把应用原型升级为可运行完整 Skill，并拿到真实昇腾数据。

必须完成：

- 扩充知识库：计算机408、通信工程、法学的考点、真题解析、院校政策、复试信息。
- 建立数据更新流程：研招网、院校研究生院、学院官网，保留来源、日期、年份和链接。
- 在昇腾环境配置 CANN、torch_npu、MindSpeed-MM。
- 按附件 7 跑通 Qwen3.5 权重转换、SFT 微调、推理调用。
- 用项目自有考研问答数据集完成精度测试日志。
- 记录首 token 时延、平均时延、吞吐、显存、训练 loss、推理成功率。
- 完成约 2000 字完整创意书和性能分析报告。
